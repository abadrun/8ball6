# Security and Gameplay Boundary

MR. SPICY is a UI/customization/source layer only.

It must not implement, improve, document, or facilitate:

- competitive gameplay automation
- aim assistance
- auto-shot or auto-play behavior
- multiplayer or server-state manipulation
- anti-cheat evasion
- DRM bypass
- license activation bypass
- subscription/payment bypass
- advertising bypass
- entitlement spoofing
- Apple signing bypass

If a future inspection discovers such functionality in an existing compiled host component, it should be recorded factually, classified with evidence and confidence, and not improved or expanded.
